很多页面第一眼很好看，但读三分钟就累。个人博客不应该这样。

我更愿意把 CSS 花在这些地方：正文宽度、段落间距、标题层级、链接状态、代码块可读性，以及暗黑模式下的对比度。

## 正文宽度

长文正文不宜过宽。中文内容尤其需要控制行长，否则眼睛很难自然回到下一行。

## 动效要轻

微交互可以有，但不要抢走文字的注意力。按钮、链接、卡片的 hover 只要让人知道“这里可以交互”就够了。

## 颜色要留余地

纯黑纯白对比太硬，高饱和强调色也容易廉价。更柔和的灰阶和低饱和主色，通常更耐看。
